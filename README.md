# Code Ontology

面向代码知识图谱与变更波及分析的本体设计。

本仓库定义一套从源码、调用、类型、数据流、数据库、API、消息、配置、测试、业务语义到构建部署的统一知识模型，并给出基于 RDFS、OWL、SHACL、图算法和规则引擎的落地方案。

## 核心原则

1. 静态分析器负责抽取事实，RDFS/OWL 负责语义统一与有限推理。
2. 图上可达不等于真实受影响，影响结论必须结合变更类型、证据和传播规则。
3. 调用、类型、数据流、数据库、API、消息、配置、测试、业务和部署关系必须分层建模。
4. 依赖图、变更图和影响图分离存储。
5. 每个影响结论都应具有可解释的证据路径、置信度、风险和测试建议。

## 状态

当前内容为第一版设计基线，后续可在此基础上实现解析器、图存储、规则引擎和影响分析服务。
