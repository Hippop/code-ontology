# Ontology Flow 交互保护

## 工作区边界

元模型治理维护平台定义；业务开发引用定义建立项目实例。平台自身开发管理与任务示例属于业务项目，不属于元模型定义编辑。保留现有工作台样式和本地后端部署方式。

## 本轮实现

| 触发条件 | 界面行为 |
| --- | --- |
| 切换仓库、模型内容、元模型绑定或认证上下文 | 清除旧扫描、分析、生成、门禁结果及写入确认 |
| 旧请求在上下文切换后返回 | 根据单调递增请求代际忽略结果，包括 A→B→A 的场景 |
| 修改覆盖选项 | 清除生成预览和写入确认 |
| 修改计划或验证证据 JSON | 清除门禁结果和已审查快照标识 |
| 元模型或项目 JSON 草稿未保存时导航 | 提供保存后离开、放弃修改、取消；保存失败保持原页 |
| 平台开发或任务示例操作执行期间导航 | 提示等待操作完成，不将页面离开当作后端取消 |
| 从 Flow 打开需求、图谱或审计工具 | 保持 Flow 挂载，返回时保留阶段及已有上下文 |

## 生成状态与写入控制

未生成 → 已预览·未应用 → 人工确认 → 已应用·待验证。

必须有当前上下文的预览才能确认写入。重新预览、模型变化及覆盖选项变化均使旧确认失效。生成成功不等于验证成功，门禁仍依据实际快照与验证证据独立判断。执行期间禁用影响本次请求的覆盖选项及门禁输入。

## 验证与边界

- `web/tests/flow-state.test.mjs` 覆盖请求代际、生成状态、保存顺序、失败阻止继续、放弃与缺失保存处理器，共 6 项。
- TypeScript 检查与 Vite 构建通过；本地首页响应正常。
- 本轮未进行浏览器点击或视觉验收，原有大体积资源包警告仍存在。
- 请求隔离只阻止旧结果覆盖界面，不取消已经提交的后端写操作。
- 项目 JSON 仍使用既有浏览器草稿存储；未新增多项目草稿版本库。
- 返回 Flow 保留上下文不等于持续监控工作树；外部代码变化后需要重新运行门禁。
- 未新增后端任务队列、跨刷新任务恢复或自动发布功能。
